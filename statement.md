# EventSphere

## Problem Statement

Managing college events manually can make event registration, participant tracking, attendance, and reporting difficult to organize. EventSphere provides a simple command-line system to manage these activities in a structured manner.

## Scope of the Project

The project covers student and organizer registration, login, event creation, event viewing, student registration and cancellation, seat availability, attendance management, and organizer-specific reports. Data is stored using files without requiring a database.

## Target Users

- **Students** – To view events, register for events, manage registrations, and check their registration status.
- **Organizers** – To create events, manage attendance, and view reports for their events.

## High-Level Features

- Student and organizer registration and login
- Event creation and viewing
- Event registration and cancellation
- Seat availability management
- Attendance management
- Organizer-specific reports
- File-based data persistence
- Input validation and error handling
- Application logging
